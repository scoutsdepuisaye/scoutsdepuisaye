Déchiffrer mon premier code

Objectif

Découvrir qu'un message peut être caché puis transmis à quelqu'un qui saura le comprendre.

Matériel

  • Une feuille.
  • Un crayon.
  • Un message codé simple (alphabet décalé ou symboles).

Exemple :

M F T B Q C S F T P O T B C M F T E F D I F U T

Clé : Chaque lettre est remplacée par la précédente dans l'alphabet.

Message :

LES ARBRES ONT BESOIN DE TOI

Déroulement

1. Le mystère (1 min)

L'ancien donne le message au nouveau :

"J'ai reçu un message important, mais il est codé. Peux-tu m'aider à le comprendre ?"

2. Enquête (3 à 5 min)

L'ancien accompagne le nouveau pour découvrir la règle :

  • observer les lettres ;
  • essayer des hypothèses ;
  • décoder progressivement.

L'objectif n'est pas la difficulté mais le plaisir de la découverte.

3. Vérification (1 min)

Lorsque le message est trouvé, l'ancien demande :

"Comment as-tu fait pour comprendre le message ?"

Le jeune explique sa démarche.

Relecture

Questions :

  • Était-il facile ou difficile de comprendre le message ?
  • Que se serait-il passé si personne n'avait réussi à le lire ?
  • Pourquoi est-il important qu'un message arrive correctement jusqu'à son destinataire ?

Conclusion scoute

Aujourd'hui, tu as découvert qu'un message n'est utile que s'il est compris par la bonne personne. Les scouts apprennent à transmettre des messages, mais aussi à transmettre ce qui est important.

Dans la loi scoute, nous choisissons d'aimer et protéger la création. Pour prendre soin de la nature, il faut souvent partager ce que l'on sait, prévenir des dangers et transmettre les bons gestes aux autres. Comme un transmetteur, chacun peut faire circuler un message qui aide à protéger le monde qui nous est confié.

D'ailleurs, n'est ce pas ce qui est écrit sur le message que tu as décrypté ;)
